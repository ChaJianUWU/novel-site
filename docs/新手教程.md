# 新手教程：10 分钟把自己的小说站跑起来

一句话：**这是一份不用登录、不要数据库、不依赖任何 AI 服务的写作站源码。** 拿到就能在自己电脑上开一个网站，
别人打开网址就能投稿、改稿，作者名必填；你还能进后台管理书目。

> 不需要 DeepSeek、不需要买了什么账号、不需要会写代码。只要一台能上网的 Windows 电脑 + Node.js。

---

## 第 0 步：先搞清楚你要的是哪一种

| 你想要 | 该看哪一段 |
| --- | --- |
| 就在自己电脑上看看、自己写、家里手机也能看 | 第 1～3 步（局域网） |
| 发给朋友、读者，让他们随时能打开 | 第 4 步（公网隧道） |
| 长期在线、电脑关了也能访问 | 第 5 步（云主机） |

---

## 第 1 步：下载

**方式 A（推荐，什么都不用装）：** 下载打好的压缩包

- 打开 <https://github.com/ChaJianUWU/novel-site>
- 点绿色 `Code` → `Download ZIP`；或直接下这个：<https://github.com/ChaJianUWU/novel-site/raw/main/packages/novel-site-1.1.0-win.zip>
- 解压到一个**没有中文、没有空格**的目录，例如 `D:\novel-site`

**方式 B（会用 git 的话）：**

```bash
git clone https://github.com/ChaJianUWU/novel-site.git
```

> 压缩包和仓库是同一份代码。压缩包里多了 `windows\` 里的双击脚本和 `docs\` 里的教程。

---

## 第 2 步：装 Node.js（只有第一次需要）

1. 打开 <https://nodejs.org/zh-cn> ，点 **LTS** 那个大按钮下载。
2. 一路「下一步」装完（默认选项就行，不用改）。
3. 验证：按 `Win + R`，输入 `cmd` 回车，在黑窗口里敲：

   ```bat
   node -v
   ```

   看到类似 `v22.11.0` 就成功了。看不到就重启一次电脑再试。

---

## 第 3 步：启动

双击 **`windows\一键启动.bat`**。

- 会弹一个黑窗口，里面打印 `地址：http://127.0.0.1:8787`，浏览器自动打开站点。
- **这个黑窗口不要关**，关了网站就停了。要停就按 `Ctrl + C` 或双击 `windows\停止.bat`。
- 第一次启动会自动生成两串密钥（同步密钥、管理员密钥），**记下来**，窗口里会打印，也存在 `data\admin-key.txt`。

手机在同一个 Wi-Fi 下想看？用黑窗口里打印的「内网地址」，例如 `http://192.168.1.7:8787`。

### 第一次试一下

1. 打开 `http://127.0.0.1:8787`，点右上角 **投稿 / 导入**。
2. 填书名、**作者名（必填，这是本站的规矩）**，拖一个 txt 进去，点「检测分章」看看分得对不对，再点「发布」。
3. 发布成功会给你一串 **18 位编辑口令**，它同时存在你这台浏览器里。**换电脑/换浏览器要靠它改稿，自己抄一份。**
4. 想改？打开书页点「编辑」，或者直接进 `http://127.0.0.1:8787/edit/<书的id>`。

### 进后台

地址：`http://127.0.0.1:8787/admin` ，把 **管理员密钥** 粘进去回车。
后台能看全部书目、章节数、字数，能改站名/公告、关掉公开投稿、导出单本 txt、删书。密钥填一次浏览器会记住。

---

## 第 4 步：让别人能打开（公网）

本机网址 `127.0.0.1` 只有你自己能访问。想让别人看，最省事的办法是开一条隧道：

1. 先确保「一键启动.bat」的窗口还开着（网站正在跑）。
2. 双击 **`windows\一键公网.bat`**。
3. 等 3～10 秒，窗口里会出现类似
   `Forwarding HTTP traffic from https://xxxx.serveo.net`
   的那个网址，**这就是可以发给别人的地址。**

注意：

- 这个窗口也不能关，关掉网址立刻失效。
- 你的电脑要开着、联网。**电脑一关或断网，网站就打不开了。**
- 免费隧道域名每次重启可能变。想固定就用 `docs\上公网.md` 里「固定子域」一节（登记一把 ssh 密钥）。
- 想要「电脑关了也能看」，见下一步。

---

## 第 5 步：想 24 小时在线（可选）

三种常见做法，任选其一，细节都在 `docs\上公网.md`：

1. **自己的一台一直开着的机器/旧笔记本**：把仓库拷过去，`npm start`，再用隧道或路由器端口映射。
2. **便宜 VPS（阿里云/腾讯云/搬瓦工都行）**：装 Node，`git clone` 下来 `npm start`，用 `pm2` 或 `systemd` 常驻，绑域名即可。
3. **PaaS 平台**：仓库里已经带了 `Dockerfile` / `render.yaml` / `Procfile`，可以直接丢给支持 Node 的平台（注意有些平台需要绑卡）。

`data\kv.json` 就是全部数据（一个文件）。搬家时把这个文件一起拷过去就完整迁移了。

---

## 数据在哪、怎么备份

- 所有书和章节都在 `data\kv.json` 里（章节正文分 key 存，也在同一个文件）。
- 备份 = 复制这个文件。恢复 = 把它放回去再启动。
- 别用记事本改它；要批量改就用后台或者 `node migrate-legacy.mjs` 之类的脚本。

## 常见问题

**双击 bat 一闪就没了？**
没装 Node，或者解压时把文件放进了带中文/空格的路径。按第 2 步装 Node，路径换成 `D:\novel-site` 这种。

**提示端口被占用（EADDRINUSE）？**
已经有一个在跑了。双击 `windows\停止.bat` 再启动，或者改端口：`set PORT=8899 && node server.mjs`。

**别人打开网址显示 502 / 打不开？**
隧道窗口关了、电脑断网、或者网站进程停了。三个都检查一遍，按顺序：启动 bat → 公网 bat。

**投稿提示「作者名必须填写」？**
这是故意的：本站没有登录，靠署名认人。

**编辑口令丢了怎么办？**
在投稿页用**完全一样的书名 + 作者名**再「发布」一次，系统会提示已存在并给你那本书的入口（不会覆盖原书）；或者找站长在后台处理。所以：发布后第一件事，把口令存进备忘录。

**能放图片、封面吗？**
当前版本只有纯文本（txt/md）。封面这类需求可以先在书简介里写外部图床链接。

**会不会有人乱删别人的书？**
删改都要口令：访客只有自己那本书的口令，管理员密钥只有你有。口令是随机的 18 位。

## 目录结构

```
novel-site/
├─ server.mjs          启动入口（零依赖 Node 服务）
├─ site-core.js        路由与接口逻辑
├─ txt.js              自动分章引擎
├─ ui.js               页面模板与样式
├─ data/kv.json        你的全部数据（备份它）
├─ windows/            双击脚本
├─ docs/               教程
├─ verify2.mjs         自测（69 项断言）
└─ Dockerfile / render.yaml / Procfile   部署用
```

自测命令：`node verify2.mjs`，看到「通过 69 项，失败 0 项」说明这份代码是好的。
